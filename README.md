# NetplanEK
Erstelle einen neuen Testplan (Vorlage verwenden) für folgende Fragestellungen. Überlege dir, wie sich diese in einzelne Testfälle zerlegen lassen. Schreibe einen vollständigen Testplan für deine Testfälle. Zeige diesen der Lehrkraft bevor du mit dem Implementieren der Testfälle beginnst.

Achte besonders auf:

eine sprechende Benennung der Testfälle. Nutze dazu auch die Annotation @DisplayName.
beim Fehlschlagen einer Assertion immer eine sinnvolle Meldung auszugeben.
Fixtures für wiederkehrende benötigte Testvoraussetzungen zu erstellen.
Testcode so kurz und einfach wie möglich zu halten - sonst ist die Wahrscheinlichkeit im Testcode Fehler zu machen hoch.
Ein Beispiel für einen Netzplan (in Excel) ist in den Ressourcen dabei und kann hier heruntergeladen werden!

 

Fragestellungen:

Wie stellen wir sicher, dass der Netzknoten genau einen Start- und einen Endknoten hat? (etwa 10 Use-Cases)
Hat die Reihenfolge der Eingabe der Knoten einen Einfluss auf die Berechnung des Pfades?
Können wir erkennen, ob ein (direkter oder indirekter) Zirkelbezug im Netzplan vorhanden ist?
Können wir für einen Knoten mehrere Vorgänger definieren?
Kann es zu einem Knoten mehrere Nachfolger geben?
